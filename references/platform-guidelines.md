# Platform affiliate/content guidelines

Reference this file when writing the caption + hashtags in Step 4 of `/createProduct`.
Apply whichever platform's rules match the product URL's domain. Update this file whenever
the user shares new/updated guidelines for a platform.

## Meesho (as of the guidelines the user provided)

Meesho affiliate creator payout rules — violating these means **no payout**, so the caption
generator must actively check against them, not just avoid contradicting them:

1. **Tag @meeshoapp** in the caption/tag of every reel. No tag = no payout.
2. **Tag the exact product shown** — only color variations are allowed as a substitution; tagging
   a different product = no payout.
3. **Call out the correct price** — check the current price on the Meesho app before posting and
   mention the exact price/price range in the caption. Incorrect price callout = no payout.
4. **Be clear with combo pricing** — if it's a pack/combo, mention the combo price; if quoting a
   per-item price, say "per item" explicitly. Incorrect/ambiguous price callout = no payout.
5. **No screenshot-only reels** — the reel must be original video showing the real product, not
   screenshots/screen recordings.
6. **Don't paste affiliate links directly into messaging apps** (Instagram, YouTube, Facebook
   DMs, WhatsApp, etc.) without an accompanying posted, visible reel.

**Do's:** tag @meeshoapp, create original content, only tag the product actually shown, call out
the correct current price, post affiliate links only on proper platforms alongside the video.

**Don'ts:** skip the official tag, post screenshot/screen-recording-only reels, tag unrelated
products, use misleading or outdated prices, paste affiliate links directly into messaging apps.

**What this means for the generated caption:** always include @meeshoapp, always state the
exact current price (or the combo/per-item price, labeled clearly) pulled from the live product
page in Step 1 — never a remembered or rounded price — and never suggest posting only a
screenshot.
